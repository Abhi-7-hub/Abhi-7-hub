✅ 📌 Project Title:
Meal Explorer App — Fetch & Display Meals Using Public API

✅ 📝 Project Description:
A simple yet interactive web application that fetches meal data from TheMealDB API and displays it in a responsive card layout. Users can click buttons to get meals by category (e.g., Seafood) or by ingredient (e.g., Chicken Breast). It uses real-time data fetching, error handling, and dynamic DOM manipulation to update the UI with smooth animations and a responsive design using CSS Grid.

✅ 💼 Key Features:
Two buttons to fetch data:

Meals by Category

Meals by Ingredient

Uses Fetch API to get data from public API

Shows results as styled cards with images and meal names

Uses CSS Grid to make responsive layout (4 cards per row)

Hover animations for better user experience

Error handling in case of network issues
