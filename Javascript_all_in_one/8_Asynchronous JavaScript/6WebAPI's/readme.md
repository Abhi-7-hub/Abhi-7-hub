📌 6. Web APIs
📖 Simple Words:
Browser ke paas kuch magic tools hote hain — jise JS use karta hai async kaam karne ke liye.
Inhe Web APIs kehte hain.

🧰 Examples of Web APIs:
setTimeout, setInterval

fetch

DOM events (click, hover)

Geolocation, Web Storage, etc.

🧪 Working:
JS setTimeout() ko Web API ko de deta hai.

Web API timer complete hone ke baad callback ko queue me bhejta hai.

Event Loop dekhta hai stack khali hai to callback ko wapas stack me bhejta hai.
