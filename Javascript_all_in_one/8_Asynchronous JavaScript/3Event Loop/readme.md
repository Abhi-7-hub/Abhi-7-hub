📌 4. Event Loop
📖 Simple Words:
Event loop ka kaam hai:

Dekhna ki stack khali hai ya nahi.

Agar stack khali ho, to queue se function uthakar stack me bhejna.

🧠 Real-Life Example:
Socho ek guard hai (Event Loop) —
Woh dekhta hai ki kitchen (stack) khali hai, to waiting room (queue) se log bula ke kitchen bhejta hai.
