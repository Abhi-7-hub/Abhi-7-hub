📌 3. Call Stack & Call Queue
📖 Call Stack:
Ek pile (stack) jaisa hota hai.

Jisme JS code ko upar se neeche push karta hai.

Kaam pura hone par pop karta hai.

📖 Call Queue:
Jab async kaam hota hai (like setTimeout, fetch) to wo queue me wait karta hai.

Jab stack khali hota hai tab Event Loop us queue se function uthata hai.

🧠 Real-Life Example:
Stack = Bartan ka stack. Last dala, pehle niklega.

Queue = School ki line. Jo pehle aaya, pehle jaayega.
